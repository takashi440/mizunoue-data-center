Amber Relay（Google Cloud プロジェクト RusticLabCounter）／最終更新：2026-10-17

このアプリについて

Amber Relay は、運営者本人が自分の作業のためだけに使う個人用ツールです。一般の利用者には提供していません。

利用するデータ

Google Docs API を使い、運営者本人の Google アカウントにある特定の Google ドキュメント（共有受信箱）を読み取り、決められたドキュメントに追記します。それ以外のデータにはアクセスしません。

保存と共有

取得した内容と認証情報は、運営者本人のコンピュータ内にのみ保存します。第三者への提供、販売、広告への利用は行いません。

アクセス権の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス権を取り消せます。
